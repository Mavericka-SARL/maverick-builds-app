Limits and what is not supported

Stated plainly so you do not design around features that are not there. Each item is either explicitly marked as not implemented in the product's own specifications or is absent from the console.

AreaNot supported today
FormulasCell addresses, SUMIF-family conditional aggregation, XLOOKUP/INDEX/MATCH, dotted property references, PARENT/CHILDREN functions, a period offset that is not a whole-number literal, JavaScript/Python/SQL formulas.
DimensionsBuilding a derived dimension from member properties in the console (schema exists, UI is partial); import preview and explicit sort/move controls in the member tree.
GridsRenaming a grid; a metric in more than one grid; collapsing hierarchy levels in the rendered grid (use the grid's Show level instead).
DashboardsUndo/redo, canvas zoom, alignment guides, layout templates, breakpoint preview; form-backed chart sources.
WorkflowsDrag-and-drop or edge drawing on the canvas (edit in the step list and panel); timeouts and escalations (SLA hours drives a one-time reminder to the people who can act on a step, nothing more); unpublish (archive instead); full BPMN.
TriggersConditions or actions on the rule itself (they belong to workflow steps); a schedule on a workflow whose trigger is an event (schedules start manual workflows).
IntegrationsSupabase (marked coming soon); Google Sheets through a person's own Google account (use a link-shared sheet or the tenant's service account).
AI DeveloperCreating integrations; undoing a single executed step (discard the whole draft revision instead).
UsersGranting developer or administrator roles; deciding application and model access (administrators); business roles, dashboard grants and access rules (Business Admin console).
RevisionsExport and import of a revision package (tenant and platform administrators only); a separate "version" axis.
AuditNo audit screen for the developer role.

Troubleshooting

SymptomCause and fix
Objects you created are missing, or turned up in another applicationThey went into the revision that was selected at the time. Models › click the right revision row; check Model and Revision in the context bar. Delete the strays where they landed.
Business users see an older model, or nothingYour revision is not active, or the model is not the business default. Models › Set active, Set as business default.
A business user cannot see a dashboardNo business role of theirs has the dashboard. Business Admin › Roles › Configure › tick the dashboard › Save dashboard access.
Add metric stays disabledA formula reference is unknown (red "✗ unknown" badge) or a Rate rule lacks an operand. Create the referenced inputs first; names are snake_case.
A metric will not tick in a gridIt already belongs to another grid; untick it there first.
Calculated cells show $0 or blankInputs were not committed (press Enter or leave the cell), or metric and grid are in different revisions. A blank means no input exists at that intersection.
A cell cannot be editedIt is calculated, a parent total, read-only or hidden by an access rule, in a locked workflow scope, or the revision is system-managed. The grid legend and "Save failed: …" message name the reason.
Preview shows no editable cellsThe grid has no input metrics, or the widget points at a different grid. Grids › Configure.
Chart widget will not addConfiguration incomplete: needs a type, a plotted dimension and the required metrics (two distinct ones for scatter).
Trigger button on a dashboard is disabledThe rule is disabled, not manual, or gone. Triggers › enable it or pick another rule in Widget Properties.
Validate reports a loop or unreachable stepPut a task or approval on the loop or route forward; give the step a route from the first step. Remember that a step without routes falls through to the next in list order.
Test Run or Publish is disabledUnsaved changes. Save first.
"Event … not found in catalog" on a workflowThe form or integration that supplied the event was deleted. Pick another event under Starts on.
Workflow start refused as a duplicate"One active instance per scope" is on and an instance with the same members is running. Turn it off for per-request processes, or finish the running instance.
Import rows rejectedWrong member codes, a calculated metric as target, a locked scope, or hidden/read-only members for your user. Fix the file or the rule; use Validate before Commit.
REST integration cannot be activatedActivation needs a successful test of the current configuration on the Response step.
AI Developer refuses to chatNo API key. AI Settings › provider, model, key › Save settings.
Unsaved-changes dialog when leavingThe dashboard canvas or workflow editor has a draft. Save or Cancel.

Glossary

Active revisionThe one revision of a model that business users see and edit.
Access rulePer-user write, read or hidden setting on a member or metric, cascading to descendants.
Aggregation ruleHow a metric's member values combine into totals: Sum, Average, Count, Rate, Formula.
Automation rule (trigger)Event → workflow. Manual rules power dashboard Trigger buttons.
Business defaultThe model of an application that business consoles open.
Business roleA named group of users (managed in Business Admin) that dashboards are granted to and tasks assigned to.
Calculated metricA metric defined by a formula; read-only.
CodeThe identity of a dimension member; labels are display only.
Context / selectorsThe dimensions a widget lets the user choose; synced widgets share one selector per dimension.
Form mappingRule that posts a form field into an input metric (Integrations › Form Records).
GridA set of metrics and dimensions shown as one table; a metric sits in at most one grid.
InstanceOne run of a workflow; keeps the definition it started with.
Input metricA metric users type into, import or post to.
IntersectionOne metric at one member per dimension; where a value lives.
Leaf / rootA member without children / without a parent.
LockWrite protection of a scope while a workflow instance about it is in progress or approved.
RevisionThe unit of change; a complete copy of a model's definitions and values.
System-managed revisionA revision written only by workflow approvals; read-only otherwise.
TaskA workflow step waiting for a person, shown in the Workflow Inbox.
WidgetOne element on a dashboard: grid, chart, form, KPI, trigger, integration, text, import.
Workflow objectWhat a workflow is about: a grid, a metric in a grid, or form records; defines its lock scope.
